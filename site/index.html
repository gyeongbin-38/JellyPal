Your typing stays yours
Keystrokes are counted, never read — the app can't see what you type. The only network call is redeeming a jelly code. No account, no ads, no tracking.
Why does Windows warn?
Jellypal isn't code-signed (a certificate costs ~$300/yr — hard to justify for a $3 slime). Choose More info → Run anyway, and only download from jellypal.fun.

before you ask

Quick questions

Windows says "unrecognized app"?
Normal for a small unsigned app — choose More info → Run anyway. Jellypal is a plain local app. No ads, no tracking, no account.
Installer or zip?
The installer puts it in C:\Jellypal and bundles WebView2. The zip runs from anywhere but needs Edge WebView2 already installed (most Windows 11 PCs have it).
Will it slow my laptop?
It's a ~2 MB app built for small machines — it sips CPU and sleeps when you do.
Does it record what I type?
No — it counts keystrokes, it can't read them. What you type never leaves your PC.
Does it need internet?
Only when you redeem a jelly code. Everything else runs fully offline.
How do I uninstall?
Installer: remove it from Windows Settings → Apps. Zip: delete the folder. Your save lives in the app's data folder and goes with it.
Mac version?
In the works. Windows first.
