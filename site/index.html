Quick questions

Windows says "unrecognized app"?
Normal for a small unsigned app — choose More info → Run anyway. Jellypal is a plain local app. No ads, no tracking, no account.
Installer or zip?
The installer puts it in C:\Jellypal and bundles WebView2. The zip runs from anywhere but needs Edge WebView2 already installed (most Windows 11 PCs have it).
Will it slow my laptop?
It's a 5 MB app built for small machines — it sips CPU and sleeps when you do.
Mac version?
In the works. Windows first.
