JELLYPAL v0.2.9 - a tiny slime ranch that lives on your desktop
================================================================

A small pixel slime lives on your screen while you work.
Feed it by typing, collect all 60 species, breed hybrids,
and decorate its little ranch.

HOW TO RUN
----------
1. Unzip anywhere.
2. Run jellypal.exe.
3. The slime appears on your desktop (bottom-right of the
   screen). A tray icon sits in the system tray.

REQUIREMENTS
------------
- Windows 10/11 (64-bit)
- Microsoft Edge WebView2 Runtime
  (preinstalled on Windows 11 and most updated Windows 10)

CONTROLS
--------
- TYPE anywhere        -> feeds the slime (keystrokes are
                          only counted, never read)
- DRAG / THROW         -> grab the slime, toss it around
- TICKLE               -> hold it and wiggle the cursor
- PET                  -> hold it and stroke slowly
- DOUBLE-CLICK         -> happy hop
- RIGHT-CLICK the slime -> open the RANCH (collection,
                          gacha pulls, breeding, nursery)
- GEAR button          -> settings (sound, size, photo,
                          album, pomodoro, motion, quit)
- COOKIE button        -> toss a snack; RIGHT-CLICK it to
                          change the treat kind
- Companion slimes     -> drag one into the SEND HOME slot at
                          the top (or RIGHT-CLICK it) to send
                          it back to the ranch

Some slimes have their own tricks - spiders dangle from
your cursor, frogs hop, and legendaries show off. Poke a
dangling Webby to spin it; whip the mouse fast to cut its
thread. Swish the cursor nearby and it might pounce; leave
it hanging and it will climb on for a ride.

GEM PACKS
---------
Bought a gem pack? Open Settings (gear) > GEMS > REDEEM
CODE and type your code (looks like JELLYPAL-C-XXXXXX-XXXX).
Codes are one-shot and stored in your save.

SAVE DATA
---------
%APPDATA%\com.jellypal.desktop\state.json
(photos from photo mode save next to it in /photos)

On Windows the save is sealed to your account (DPAPI) plus a rollback
checkpoint — editing or swapping it won't parse, and pasting an old copy
back resets to a clean ranch. Back up by exporting before a reinstall,
then drop the file into a fresh install's folder to adopt it.
